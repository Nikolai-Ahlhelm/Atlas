# Authoring Content

Atlas keeps content creation simple: add folders for sections and Markdown files for pages.

## Recommended workflow

- Create a folder for a topic area
- Add a `category.json` file to set the sidebar label and order
- Use `index.md` for the category landing page
- Add more Markdown files for deeper pages

## Helpful frontmatter

- `title` sets the page title
- `description` adds summary text below the title
- `roles` limits access to selected roles
- `owner`, `version`, and `reviewDate` fill the metadata card

## Good starter habits

Keep sections short, name files clearly, and treat the default pages as examples for structure, tone, and metadata.
