# Administration and Access

The Atlas admin area is where workspace behavior is configured.

## Users and roles

- `Users` is the default role for regular readers
- `Admins` receive full administrative access
- Additional roles can be created later if your workspace needs them

## Workspace settings

Admins can update the workspace name, sidebar title, logo, login copy, default theme, and footer text without touching code.

## Factory reset

The admin portal also includes a factory reset action. It clears the SQLite database, recreates the default Admin account, and restores the starter configuration so the workspace can begin fresh again.
