# How Atlas Works

Atlas reads content from the `content` folder and builds a documentation experience from plain Markdown files.

## What users see

- A home page from `content/home.md`
- A sidebar generated from folders, `category.json`, and Markdown files
- A document view with metadata, access labels, and a table of contents

## What admins control

- Users, passwords, and role assignments
- Branding, login copy, colors, and menu links
- Content reloads after Markdown changes

## Why this template exists

This starter set is meant to be both a reference and a clean foundation. Replace it with your own content once your workspace structure is ready.
