# Welcome to Atlas

Atlas is a lightweight documentation portal that turns folders of Markdown files into a private knowledge base for your team.

This starter workspace is intentionally small so new users can understand the product by reading the product.

<div class="home-grid">
  <section>
    <h2>Learn the structure</h2>
    <p>The sidebar shows how categories, index pages, and regular Markdown documents appear in navigation.</p>
  </section>
  <section>
    <h2>See access control</h2>
    <p>Documents can be visible to everyone or limited to selected roles such as Users and Admins.</p>
  </section>
  <section>
    <h2>Customize the experience</h2>
    <p>The admin area lets you change branding, login copy, theme options, roles, and user access.</p>
  </section>
